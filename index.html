🐍 PYTHON LEARNING

Python basics for beginners.

1. Print

Display a message on the screen.

print("Hello World!")

2. Variables

Store information in a variable.

name = "Jaitish"
print(name)

3. Data Types

Learn strings, integers and other data types.

age = 19
city = "India"
print(age, city)

4. Operators

Use operators for calculations.

a = 10
b = 5
print(a + b)

5. If / Else

Make decisions in your program.

score = 80
if score >= 50:
    print("Pass")
else:
    print("Try again")

6. Loops

Repeat an action multiple times.

for i in range(5):
    print(i)

7. Lists

Keep multiple values together.

games = ["Racing", "Memory"]
print(games)

8. Functions

Organise reusable blocks of code.

def hello():
    print("Hello Jaitish!")

hello()
