🐍 PYTHON LEARNING

Learn Python step by step — from beginner to projects

1️⃣ Python Kya Hai?

Python ek easy programming language hai. Isse apps, games, websites aur AI projects banaye ja sakte hain.

2️⃣ First Program

Python ka sabse basic program:

print("Hello Jaitish!")

3️⃣ Variables

Data store karne ke liye variables use hote hain.

name = "Jaitish" age = 13 print(name)

4️⃣ Calculations

Python calculator ki tarah bhi kaam karta hai.

a = 10 b = 5 print(a + b) print(a - b) print(a * b) print(a / b)

5️⃣ User Input

User se information lene ke liye input use karte hain.

name = input("Your name: ") print("Hello", name)

6️⃣ If / Else

Condition check karne ke liye if aur else use hote hain.

age = 13 if age >= 13: print("Welcome") else: print("Keep learning")

7️⃣ Loops

Ek kaam ko baar-baar karne ke liye loop use hota hai.

for i in range(5): print(i)

8️⃣ Functions

Code ko reusable banane ke liye functions use hote hain.

def hello(): print("Hello Jaitish!") hello()

9️⃣ Python Projects

Python seekhne ke baad calculator, games, automation aur AI projects bana sakte ho.

🔟 Advanced Python

Next level par Python libraries, OOP, AI, OpenCV aur game development seekho.
