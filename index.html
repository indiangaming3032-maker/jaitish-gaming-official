🐍 PYTHON LEARNING

Learn Python step by step — from beginner to projects

1️⃣ Python Kya Hai?

Python ek easy programming language hai. Isse apps, games, websites aur projects banaye ja sakte hain.

2️⃣ First Program

Python ka sabse basic program:

print("Hello Jaitish!")

3️⃣ Variables

Data store karne ke liye variables use hote hain.

name = "Jaitish" age = 14 print(name) print(age)

4️⃣ Data Types

Python me alag-alag types ka data hota hai.

name = "Jaitish" age = 14 print(type(name)) print(type(age))

5️⃣ Operators

Python me calculations ke liye operators use hote hain.

a = 10 b = 5 print(a + b) print(a - b) print(a * b) print(a / b)

6️⃣ If / Else

Condition ke according program decision leta hai.

score = 100 if score >= 50: print("You Win!") else: print("Try Again!")

7️⃣ Loops

Ek kaam ko baar-baar karne ke liye loops use hote hain.

for i in range(5): print("JAITISH GAMING")

8️⃣ Lists

Ek variable me multiple values store kar sakte hain.

games = ["Racing", "Reaction", "Memory"] print(games) print(games[0])

9️⃣ Functions

Reusable code banane ke liye functions use hote hain.

def hello(): print("Welcome to Jaitish Gaming!") hello()

🔟 Mini Python Project

Ek simple number guessing game.

import random number = random.randint(1, 10) guess = int(input("Guess 1-10: ")) if guess == number: print("You Win!") else: print("Try Again!")
